# Prometheus & Grafana Observability Platform

A hands-on monitoring and observability project built with open-source technologies.

## Project Goals

- Understand Prometheus and Grafana
- Collect and analyze system and application metrics
- Build monitoring dashboards
- Implement alerting and incident detection
- Explore logs, traces, and distributed observability
- Automate configuration validation with GitHub Actions

## Technology Stack

- Prometheus
- Grafana
- Docker Compose
- Alertmanager
- Loki & Tempo
- OpenTelemetry
- Python / FastAPI
